Roadmap de Desenvolvimento — Módulo H

Guia de implementação do frontend do dashboard operacional. Nove etapas para transformar a API REST/WebSocket do Módulo H em uma interface de consciência situacional em tempo real.

[01]

Arquitetura do Backend

O Módulo H expõe API REST (FastAPI, porta 8001) e WebSocket (porta 8002). O frontend consome ambos e precisa tratar reconexão automática.

RESTGET /api/h/helicopters
RESTGET /api/h/telemetry/{id}
RESTGET /api/h/fleet/status
RESTGET /api/h/alerts
WSws://.../ws/telemetry
WSws://.../ws/alerts
WSws://.../ws/control
[02]

Layout em Três Painéis

Estrutura do Real-Time Dashboard:

  • Esquerdo (320px): lista de aeronaves com status e dados resumidos
  • Central: mapa Leaflet com tema escuro e marcadores
  • Direito (360px): telemetria, alertas e resultados de imagens
[03]

WebSocket com Reconexão

connectTelemetrySocket() abre a conexão; no onclose agenda reconexão em 5s via setTimeout. Essencial em redes instáveis.

[04]

Modelo de Telemetria

Campos mapeados diretamente para as células da UI:

  • location: lat, lng, altitude, accuracy
  • attitude: roll, pitch, yaw
  • velocity: horizontal, vertical, heading
  • engine: rpm, temperature, oil_pressure, fuel_flow
  • fuel: level, consumption, remaining_time
  • systems: battery_voltage, etc.

Campos ausentes exibem --- para não quebrar a interface.

[05]

Alertas com Severidade

Backend classifica em critical, warning e info. Frontend aplica borda esquerda colorida (vermelho, âmbar, verde).

  • Info: auto-remove em 30s
  • Critical: permanece até acknowledge
  • Endpoint: POST /api/h/alerts/acknowledge
[06]

Processamento de Imagens

O backend retorna análises de imagens aéreas com objetos detectados (veículos, edifícios, pessoas) e avaliação de danos.

Em produção, substituir tags por thumbnails via GET /api/h/images/analysis/{id}.

[07]

Fallback com Dados Simulados

loadSimulatedFleet() cria três helicópteros em estados diferentes (in_flight, grounded, taxiing) e simula atualizações de posição, telemetria, alertas e imagens.

Permite validar a UI antes da integração real com a API.

[08]

Identidade Visual Matrix

Paleta preta com verde #00ff41, fontes Share Tech Mono e JetBrains Mono, scanlines sutis e prefixos de terminal (>, //, $).

Diferencia o Módulo H como solução técnica e operacional.

[09]
