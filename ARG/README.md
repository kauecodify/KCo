# KCo/ARG — TURNKEY BUSINESS EXPANSION

> **Operacao Empresarial Chave na Mao | Republica Argentina**

KCo/ARG e a expansao turnkey (chave na mao) da plataforma KCo para o mercado argentino, projetada para entrega completa de uma operacao empresarial funcional, juridicamente estruturada, tecnologicamente integrada, comercialmente habilitada e preparada para processar operacoes reais dentro dos limites regulatorios aplicaveis.

---

## VISAO GERAL DO PROJETO

Este projeto implementa o modelo TURNKEY de expansao empresarial para a Argentina, seguindo a metodologia de execucao por dependencias e condicoes de aprovacao, sem depender de cronogramas fixos ou prazos predeterminados.

### Principios Fundamentais

1. **Execucao por Entregas**: Cada etapa depende exclusivamente da entrega, validacao tecnica, aprovacao juridica e autorizacao operacional correspondente
2. **Conformidade Absoluta**: Respeito integral as legislacoes argentinas e brasileiras aplicaveis
3. **Transparencia Total**: Todas as dependencias, riscos e pendencias sao identificados expressamente
4. **Qualidade sobre Velocidade**: Nao ha prazos fixos; a qualidade e validacao determinam o progresso

## METODOLOGIA DE EXECUCAO

### Etapas de Execucao

O projeto e organizado em 6 etapas principais, cada uma com dependencias claras e condicoes de aprovacao:

#### ETAPA A — DIAGNOSTICO
- **Objetivo**: Identificar requisitos, recursos, riscos, dependencias e estrutura necessaria
- **Entregas**:
  - Diagnostico juridico e societario
  - Diagnostico regulatorio
  - Diagnostico financeiro
  - Diagnostico tecnologico
  - Diagnostico comercial
  - Matriz de riscos e dependencias

#### ETAPA B — ESTRUTURACAO
- **Objetivo**: Executar a organizacao societaria, juridica, financeira e operacional
- **Entregas**:
  - Entidade empresarial constituida
  - Documentacao societaria
  - Estrutura de governanca
  - Modelagem financeira
  - Plano de compliance

#### ETAPA C — IMPLEMENTACAO
- **Objetivo**: Construir a tecnologia, desenvolver integracoes e estruturar canais comerciais
- **Entregas**:
  - Infraestrutura tecnologica funcional
  - Integracoes homologadas
  - Estrutura comercial documentada
  - Procedimentos operacionais

#### ETAPA D — HOMOLOGAÇAO
- **Objetivo**: Validar a infraestrutura, controles internos, contratos e autorizacoes
- **Entregas**:
  - Validacao tecnologica
  - Validacao de compliance
  - Validacao juridica
  - Validacao operacional
  - Autorizacoes obtidas

#### ETAPA E — OPERACAO
- **Objetivo**: Ativar servicos autorizados, estabelecer parcerias e processar operacoes reais
- **Entregas**:
  - Servicos autorizados ativos
  - Parcerias estabelecidas
  - Primeiro GMV real
  - Operacoes em producao

#### ETAPA F — TRANSFERENCIA
- **Objetivo**: Entregar a operacao, documentacao, governanca e conhecimento a equipe do CLIENTE
- **Entregas**:
  - Operacao completa entregue
  - Documentacao completa
  - Transferencia de conhecimento
  - Treinamento da equipe
  - Relatorio de conclusao

### Regras de Transicao entre Etapas

1. **Nao ha transicao automatica**: Cada etapa so e considerada concluida apos validacao e aprovacao expressa
2. **Evidencias verificaveis**: Todas as entregas devem ter evidencias documentadas e verificaveis
3. **Dependencias explicitas**: As dependencias entre atividades sao identificadas e gerenciadas
4. **Pendencias transparentes**: Itens pendentes sao identificados expressamente, sem serem apresentados como entregas concluidas

## DIRETRIZES JURIDICAS INEGOCIAVEIS

A operacao devera respeitar integralmente as legislacoes argentinas e brasileiras aplicaveis.

### Controles Obrigatorios

Estabelecer controles para impedir:

- Operacoes financeiras sem autorizacao
- Captacao irregular de recursos
- Movimentacoes cambiais nao permitidas
- Lavagem de dinheiro
- Ocultacao de beneficiarios finais
- Uso indevido de dados pessoais ou financeiros
- Falsificacao de documentos
- Simulacao de transacoes
- Intermediacao nao autorizada
- Utilizacao de parceiros sem habilitacao necessaria

### Principios de Compliance

1. **Fundamentacao Legal**: Toda interpretacao regulatoria deve ser fundamentada em legislacao vigente e fontes oficiais
2. **Consultoria Juridica**: Quando houver duvida juridica, encaminhar a questao ao advogado habilitado na jurisdicao competente antes de prosseguir
3. **Nao Contornar Controles**: Nao utilizar estruturas societarias, intermediarios, contratos, contas ou mecanismos tecnologicos para contornar controles nacionais
4. **Autorizacao Previa**: Nenhuma atividade sujeita a autorizacao podera entrar em producao antes da obtencao da habilitacao correspondente

## CRITERIOS DE ACEITACAO

A operacao somente sera considerada TURNKEY quando apresentar:

### Criterios Obrigatorios

- [ ] Estrutura juridica constituida e regular
- [ ] Autorizacoes necessarias identificadas e obtidas
- [ ] Compliance implementado
- [ ] Tecnologia funcional e homologada
- [ ] Integracoes autorizadas e testadas
- [ ] Estrutura comercial documentada
- [ ] Tres LOIs assinadas, conforme viabilidade e aprovacao
- [ ] Capacidade de processar operacoes reais autorizadas
- [ ] GMV real comprovado, quando aplicavel
- [ ] Governanca operacional
- [ ] Documentacao tecnica e juridica
- [ ] Equipe capacitada para assumir a operacao

### Criterios de Qualidade

- Documentacao suficiente para permitir que a equipe do CLIENTE administre a operacao sem dependencia permanente dos desenvolvedores
- Todas as pendencias que dependam de terceiros ou de decisoes de autoridades identificadas expressamente
- Evidencias verificaveis para todas as entregas

## COMO COMECAR

### Requisitos Minimos

- Python 3.11+
- PostgreSQL 15+
- Redis 7+
- Docker 24+
- Docker Compose 2.x

### Instalacao Local

```bash
cd ARG

# Criar ambiente virtual
python3 -m venv .venv
source .venv/bin/activate  # Linux/macOS

# Instalar dependencias
pip install -r requirements.txt

# Configurar variaveis de ambiente
cp .env.example .env
# Editar .env com suas configuracoes

# Inicializar banco de dados
python scripts/seed.py

# Iniciar servidor
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

### Instalacao com Docker

```bash
cd ARG

# Copiar e configurar variaveis de ambiente
cp .env.example .env
# Editar .env

# Construir e iniciar containers
docker compose up -d --build
```
